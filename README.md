# ⚡ MyStat Helper — Telegram Bot & Mini App для mystat.itstep.org

Полнофункциональный помощник студента **Компьютерной Академии ШАГ (IT Step Academy)** в виде Telegram-бота и интерактивного веб-приложения **Telegram Mini App**.

Проект полностью оптимизирован для бесплатного тарифа **Render.com (Free Tier)** и содержит встроенную систему **Anti-Sleep (само-пинг)**, чтобы сервис не засыпал.

---

## 🌟 Основные возможности

1. 📚 **Домашние задания:**
   - Автоматический просмотр всех висящих (активных) и просроченных заданий.
   - Фильтры по категориям: *Висящие*, *Активные*, *Просроченные*, *Проверенные*, *Все*.
   - Прямая кнопка **«📥 Скачать задание»** для загрузки прикреплённых преподавателем файлов через безопасный прокси без ограничений CORS.
   - Просмотр оценок и комментариев преподавателя к сданным работам.

2. 📅 **Расписание на все дни:**
   - Интерактивный календарь на любой месяц года.
   - Быстрый просмотр: *Сегодня*, *Завтра*, *Весь месяц*.
   - Горизонтальная лента дней с отображением времени пар, предмета, преподавателя и номера аудитории (или Zoom/Online).

3. ⭐ **Оценки за сегодня:**
   - Отображение оценок за текущий день (классная работа, домашнее задание, лабораторная).
   - История последних полученных оценок и статистика посещаемости.

4. 🏆 **Таблица лидеров:**
   - Рейтинг успеваемости с переключением: *Моя группа* / *Весь поток*.
   - Визуальный пьедестал для топ-3 с медалями (🥇, 🥈, 🥉) и кристаллами (💎).
   - Подсветка позиции текущего студента в общем списке.

5. 💎 **Профиль и геймификация:**
   - Отображение текущего баланса кристаллов (алмазов 💎) и монет (🪙).
   - Уровень студента, группа и статус подключения.

6. 🤖 **Telegram Бот + Mini App:**
   - Запуск Mini App в один клик прямо из Telegram.
   - Быстрые команды в чате: `/hw` (домашка со ссылками), `/schedule` (расписание), `/grades` (оценки), `/leaders` (лидеры).

7. ⚡ **Render.com Free Tier + Anti-Sleep:**
   - Встроенный сервис само-пинга (`/ping`), который каждые 9 минут делает HTTP-запрос к самому себе, предотвращая переход бесплатного инстанса Render в спящий режим.

## 🚀 Быстрый старт (Локально)

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка переменных окружения
Создайте файл `.env` (скопировав из `.env.example`):
```env
BOT_TOKEN=ваш_токен_бота_от_BotFather
PORT=3000
APP_URL=http://localhost:3000
PING_INTERVAL_MINUTES=9
```
*(Если `BOT_TOKEN` оставить пустым, Mini App всё равно будет работать в браузере по адресу `http://localhost:3000`)*.

### 3. Запуск
```bash
npm start
```
Откройте в браузере: `http://localhost:3000`

## 🤖 Настройка Telegram Бота через @BotFather

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`.
2. Введите имя бота (например, `MyStat Helper`) и юзернейм (например, `mystat_step_helper_bot`).
3. Скопируйте полученный **HTTP API Token** в переменную `BOT_TOKEN`.
4. Для настройки кнопки Mini App в меню чата бота:
   - В `@BotFather` отправьте `/mybots` -> выберите вашего бота.
   - Перейдите в **Bot Settings** -> **Menu Button** -> **Configure menu button**.
   - Отправьте URL вашего развернутого приложения (например, `https://your-app.onrender.com`).
   - Назовите кнопку: `🚀 MyStat`.
5. Также можно настроить команду `/newapp` для создания прямого шортката веб-приложения.

## ☁️ Развёртывание на Render.com (Бесплатный тариф)

Проект полностью укладывается в бесплатный лимит Render.com (Free Web Service, 512 MB RAM, 0.1 CPU).

### Шаги:
1. Загрузите этот проект в свой репозиторий на **GitHub** или **GitLab**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of MyStat Helper"
   git remote add origin https://github.com/ВАШ_ЮЗЕРНЕЙМ/mystat-tg-miniapp.git
   git push -u origin main
   ```

2. Зайдите на [dashboard.render.com](https://dashboard.render.com/) и нажмите **New +** -> **Web Service**.
3. Подключите ваш репозиторий GitHub.
4. Укажите параметры сервиса:
   - **Name:** `mystat-tg-miniapp` (или любое другое)
   - **Region:** Frankfurt (или любой ближайший к вам)
   - **Branch:** `main`
   - **Runtime:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** `Free`
5. В разделе **Environment Variables** добавьте:
   - `BOT_TOKEN`: токен вашего Telegram-бота
   - `NODE_ENV`: `production`
   - `PING_INTERVAL_MINUTES`: `9`
6. Нажмите **Create Web Service**.

> 💡 **Как работает Anti-Sleep:**
> Render.com автоматически пробрасывает переменную `RENDER_EXTERNAL_URL` (например, `https://mystat-tg-miniapp.onrender.com`). Наш встроенный модуль `src/pinger.js` каждые 9 минут выполняет запрос к эндпоинту `/ping`, благодаря чему Render видит входящую сетевую активность и не переводит сервис в спящий режим!

## 🔒 Безопасность данных

- Все запросы выполняются напрямую к официальному API `https://msapi.itstep.org/api/v2`.
- Токены и пароли хранятся локально в безопасном JSON-хранилище `data/users.json` и никогда не передаются сторонним лицам.
- Скачивание файлов домашних заданий происходит через прозрачный стриминговый прокси-эндпоинт `/api/download-proxy`, исключающий проблемы с CORS и Referer в браузере Telegram.
