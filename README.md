# ⚡ MyStat Helper — Telegram Bot & Mini App для mystat.itstep.org

Полнофункциональный помощник студента **Компьютерной Академии ШАГ (IT Step Academy)** в виде Telegram-бота и интерактивного веб-приложения **Telegram Mini App**.

Проект полностью оптимизирован для бесплатного тарифа **Render.com (Free Tier)**, поддерживает **Single-User Mode (режим «только для себя» с авто-авторизацией из переменных окружения)**, защиту доступа по Telegram ID и гибкое управление само-пингом (**Anti-Sleep**).

---

## 🌟 Основные возможности

1. 👤 **Режим «Только для себя» (Single-User Mode):**
   - Учётные данные MyStat (`MYSTAT_USERNAME` и `MYSTAT_PASSWORD`) указываются один раз в переменных окружения.
   - Сервер **автоматически** логинится в MyStat и кэширует сессию в оперативной памяти.
   - При открытии Telegram Mini App **не появляется окно ввода логина/пароля** — приложение открывается сразу.
   - При любых перезапусках контейнера на Render.com авторизация не сбрасывается.

2. 🔒 **Приватный Telegram-бот:**
   - Переменная `MY_TELEGRAM_ID` защищает бота: бот отвечает **только вам**.
   - Посторонним пользователям выводится сообщение: `⛔ Доступ ограничен. Это приватный бот.`

3. 📚 **Домашние задания и скачивание:**
   - Автоматический просмотр всех висящих (активных) и просроченных заданий.
   - Фильтры по категориям: *Висящие*, *Активные*, *Просроченные*, *Проверенные*, *Все*.
   - Прямая кнопка **«📥 Скачать задание»** через безопасный прокси-эндпоинт `/api/download-proxy`.
   - Просмотр оценок и комментариев преподавателя к сданным работам.

4. 📅 **Расписание на все дни:**
   - Интерактивный календарь на любой месяц года.
   - Быстрый просмотр: *Сегодня*, *Завтра*, *Весь месяц*.
   - Время пар, название предмета, преподаватель и номер аудитории (или Zoom/Online).

5. ⭐ **Оценки за сегодня:**
   - Отображение оценок за текущий день (классная работа, домашнее задание, лабораторная).
   - История последних полученных оценок и посещаемости.

6. 🏆 **Таблица лидеров:**
   - Рейтинг успеваемости с переключением: *Моя группа* / *Весь поток*.
   - Визуальный пьедестал для топ-3 с медалями (🥇, 🥈, 🥉) и кристаллами (💎).
   - Подсветка вашей позиции в списке.

7. ⏱️ **Управление само-пингом (Render Anti-Sleep):**
   - Переменная `ENABLE_SELF_PINGER=true/false` позволяет включать или отключать встроенный само-пинг.
   - При значении `false` внутренний таймер отключается (удобно, если вы настроили внешний пингер, например [cron-job.org](https://cron-job.org/), чтобы экономить 750 бесплатных часов Render).

| `BOT_TOKEN` | Токен Telegram-бота от @BotFather | `8834073745:AAFEjQfP9XQWEQMHedaVrycY0soLD-e1-7Y` |
| `MYSTAT_USERNAME` | Логин в MyStat | `grudi_ms97` |
| `MYSTAT_PASSWORD` | Пароль в MyStat | `S8@8hjqf` |
| `MY_TELEGRAM_ID` | Ваш личный Telegram ID | `1186053117` |
| `ENABLE_SELF_PINGER` | Включение встроенного пингера | `true` или `false` |
| `PING_INTERVAL_MINUTES` | Интервал пинга в минутах | `9` |
| `PORT` | Порт сервера | `3000` |
| `APP_URL` | URL приложения (на Render выставляется сам) | `https://your-service.onrender.com` |

## 🚀 Быстрый запуск локально

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск сервера и бота
npm start
```
Приложение откроется на `http://localhost:3000`, сразу загрузит ваш профиль MyStat и покажет все данные.

## ☁️ Развёртывание на Render.com (Free Tier)

1. Загрузите код в свой репозиторий на **GitHub**:
   ```bash
   git add .
   git commit -m "Update single user mode"
   git push origin main
   ```
2. В панели [dashboard.render.com](https://dashboard.render.com/) нажмите **New +** -> **Web Service**.
3. Выберите репозиторий.
4. Параметры:
   - **Environment:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Instance Type:** `Free`
5. В разделе **Environment Variables** укажите:
   - `BOT_TOKEN` = `8834073745:AAFEjQfP9XQWEQMHedaVrycY0soLD-e1-7Y`
   - `MYSTAT_USERNAME` = `grudi_ms97`
   - `MYSTAT_PASSWORD` = `S8@8hjqf`
   - `MY_TELEGRAM_ID` = `1186053117`
   - `ENABLE_SELF_PINGER` = `true` (или `false`, если используете cron-job.org)
   - `PING_INTERVAL_MINUTES` = `9`
6. Нажмите **Create Web Service**.

## 🤖 Подключение кнопки Mini App в Telegram

1. Откройте в Telegram [@BotFather](https://t.me/BotFather).
2. Отправьте `/mybots` -> выберите бота (`@statsbotformebot`).
3. Перейдите в **Bot Settings** -> **Menu Button** -> **Configure menu button**.
4. Вставьте ссылку на ваш сервис с Render (например, `https://mystat-tg-miniapp.onrender.com`).
5. Введите название кнопки: `⚡ MyStat Helper`.

Теперь при открытии бота меню запускает ваше персональное Mini App без единого запроса логина или пароля!
